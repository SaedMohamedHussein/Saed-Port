# 🔬 Current Research

## Adaptive Variational Quantum Regression-Aided Extended Kalman Filter

<p align="center">
  <img src="assets/research-system.png" width="850" alt="VQR EKF Research System">
</p>

My research develops a hybrid **quantum-classical state estimation framework**.

The Extended Kalman Filter provides the classical model-based estimate, while a Variational Quantum Regression model learns correction information from measurement innovations and estimation history.

### Research Areas

* Extended Kalman Filter
* Variational Quantum Regression
* Quantum Neural Networks
* Nonlinear State Estimation
* Adaptive Filtering
* Innovation Analysis
* GNSS Navigation
* Non-Gaussian Measurement Noise
* Gaussian Mixture Noise
* Gauss-Markov Noise
* Random Measurement Outliers

### Main Tools

`Python` `Qiskit` `PyTorch` `NumPy` `SciPy` `Pandas` `Matplotlib`
